# QUIZMANIA: Run For The Answer

## Core Idea

Игрок выбирает количество вопросов и категорию. AI создаёт quiz-run. Каждый вопрос превращается в лабиринт: надо добежать до правильного ответа. Чем дальше игрок проходит серию, тем опаснее становятся преследователи. За успешные забеги персонаж эволюционирует через скины знаний и получает маленькие усиления.

## Полная концепция

### Краткий сюжет

Игрок - маленький "пожиратель знаний", который попал в Лабиринт Разума. Каждый вопрос - это закрытая комната памяти. Чтобы выбраться, нужно не нажать кнопку, а физически добежать до правильного ответа.

Преследователи - это не просто враги, а "ментальные помехи":

- сомнение
- путаница
- паника

Чем ближе игрок к финалу, тем сильнее мозг сопротивляется. После успешных забегов персонаж становится умнее, быстрее и увереннее, открывая новые формы.

## User Flow

1. Пользователь открывает сайт.
2. На главном экране сразу видит:
   - своего персонажа Pac-Man-style
   - текущий skin
   - прогресс до следующего skin
   - поле количества вопросов
   - кнопку Choose Category
3. Пользователь вводит количество вопросов:
   - минимум: 5
   - рекомендуемо: 5, 10, 15
   - максимум для MVP: 15
4. Нажимает Choose Category.
5. Открывается pop-up с 5 категориями.
6. Пользователь выбирает категорию.
7. AI генерирует вопросы, ответы и fun facts.
8. Начинается игра.
9. В каждом вопросе:
   - сверху показан вопрос
   - на поле 4 ответа в разных зонах
   - игрок управляет персонажем
   - надо добежать до правильного ответа
   - преследователи мешают
10. Если игрок дошёл до правильного ответа:
    - засчитывается правильный ответ
    - показывается fun fact
    - начинается следующий вопрос
11. Если игрок дошёл до неправильного ответа:
    - теряет жизнь
    - показывается короткое объяснение
    - вопрос считается проваленным
12. Если игрок сталкивается с преследователем:
    - теряет жизнь
    - вопрос можно продолжить, если жизни остались
13. После всех вопросов или потери всех жизней:
    - показывается результат
    - если run успешный, начисляется прогресс к skins
    - если достигнут порог, открывается новый skin
    - игрок может начать новый run

## Что считается успешным run

Чтобы игра не была слишком жёсткой:

| Количество вопросов | Успешный run |
|---:|---:|
| 5 | 4+ правильных |
| 10 | 7+ правильных |
| 15 | 11+ правильных |

Формула: примерно 75% правильных, но для 5 вопросов чуть мягче.

## Топ-5 категорий для квиза

| Категория | Почему она хороша | Примеры вопросов |
|---|---|---|
| Movies & Series | массовая, легко играть, хорошо для демо | фильмы, персонажи, цитаты, актёры |
| Science & Nature | много вау-фактов | космос, животные, тело человека, физика |
| History & Myths | даёт атмосферу приключения | древние цивилизации, мифология, известные события |
| Games & Internet Culture | ближе к аудитории хакатона/AI-челленджа | игры, мемы, технологии, поп-культура |
| Random Fun Facts | самая реиграбельная и смешная | странные факты, неожиданные рекорды, абсурдные знания |

Важно: у каждого вопроса обязательно есть fun fact, который появляется после ответа.

## Преследователи

Усложнение строго по проценту пройденных вопросов.

### Расчёт стадии

Берём:

```text
progress = completedQuestions / totalQuestions
```

Где `completedQuestions` - количество уже завершённых вопросов.

| Прогресс run | Стадия | Активные преследователи |
|---:|---|---|
| 0% - 29% | Stage 1 | Doubt |
| 30% - 79% | Stage 2 | Doubt + Confusion |
| 80% - 100% | Stage 3 | Doubt + Confusion + Panic |

## Типы преследователей

| Преследователь | Уровень | Поведение | Игровая роль |
|---|---:|---|---|
| Doubt | 1 | Медленно движется к игроку простым путём | Базовое давление |
| Confusion | 2 | Движется не всегда к игроку, иногда идёт к ближайшему ответу и перекрывает путь | Заставляет менять маршрут |
| Panic | 3 | Быстрее остальных, каждые несколько секунд делает короткий рывок | Финальное напряжение |

### Doubt

- появляется с первого вопроса
- скорость низкая
- преследует игрока напрямую
- если догнал, снимает 1 жизнь

Смысл: игрок сразу понимает, что стоять нельзя.

### Confusion

- появляется с 30% пройденного run
- иногда не гонится за игроком, а блокирует одну из комнат с ответами
- может менять цель каждые 3-4 секунды

Смысл: игроку приходится не просто знать ответ, а искать безопасный маршрут.

### Panic

- появляется с 80% пройденного run
- быстрее Doubt и Confusion
- раз в 5-7 секунд ускоряется на 1 секунду
- визуально должен выглядеть опаснее

Смысл: финальные вопросы становятся нервными и запоминающимися.

## Жизни

База:

- игрок начинает с 3 жизнями
- неправильный ответ: -1 жизнь
- столкновение с преследователем: -1 жизнь
- если жизней 0: run заканчивается

Со skin-бонусом можно получить максимум 4 жизни.

## Power-ups на поле

| Power-up | Эффект | Условия появления |
|---|---|---|
| Hint Pellet | убирает 1 неправильный ответ с поля | доступен с базового skin, появляется примерно 1 раз на 3 вопроса |
| Freeze | замораживает преследователей на 3 секунды | открывается skin 2, появляется случайно |
| Focus | показывает направление к правильному ответу на 1 секунду | открывается skin 3, появляется редко после 50% run |

## Скины и прогресс

Всего 5 скинов. Первый базовый уже есть. Новые открываются за успешные runs.

| Уровень | Skin | Как открыть | Power-up / бонус | Идея внешнего вида |
|---:|---|---|---|---|
| 0 | Base Muncher | доступен сразу | базовая скорость, 3 жизни, Hint Pellet может появляться | обычный жёлтый персонаж |
| 1 | Notebook Rookie | после 1 успешного run | +0.25 к скорости | очки, маленький блокнот |
| 2 | Memory Sprinter | после 3 успешных runs | +1 запасная жизнь, максимум 4 | синий след памяти |
| 3 | Focus Hacker | после 6 успешных runs | открывает Focus power-up | неоновый контур, glitch-очки |
| 4 | Quiz Oracle | после 10 успешных runs | Freeze длится +1 сек и появляется чуть чаще | золотой/космический образ |

Важно для баланса: бонусы должны помогать, но не ломать игру.

## Логика скинов

- Прогресс хранится локально.
- После каждого run проверяем, успешный ли он.
- Если успешный:
  - `successfulRuns += 1`
  - проверяем unlock thresholds: 1, 3, 6, 10
- Если открыт новый skin:
  - показываем красивый unlock screen
  - предлагаем сразу надеть skin

## Система результата

После run показываем:

- категория
- количество вопросов
- правильные ответы
- точность
- оставшиеся жизни
- сколько успешных runs всего
- прогресс до следующего skin
- лучший fun fact из run
